医院 HIS 双向接口 接口帮助

出向按 REST/JSON 或 SOAP/XML 上报挂号/结算/发药（Outbox 补偿 + 重试监控）；入向接收 HIS 推送的患者主数据与基础字典。
1. 出向同步2. 入向开放3. Scope 隔离4. 测试

1. 出向同步

  • 协议适配器：REST/JSON 或 SOAP/XML。
  • 网关地址、机构代码、AppID/AppSecret：对接凭证（请求签名 HMAC-SHA256）。
  • 实时同步开关：挂号 / 结算 / 发药；任务写入 his_sync_tasks 异步入队，失败可重试。

2. 入向开放

  • 入向鉴权 Token：外部携带 X-HIS-Token: <Token>（或 Bearer / ?token=）。
  • Token 过期时间 / 状态 / 授权 Scope：生命周期与最小权限。
  • IP 白名单：建议限定 HIS 出口。
方法路径说明
GET/api/external/his/read?action=ping连通性自检
GET/api/external/his/read?action=patient_get患者查询（id_card / patient_no）
GET/api/external/his/read?action=visit_list就诊列表
GET/api/external/his/read?action=visit_status就诊状态
GET/api/external/his/read?action=order_list开单明细
POST/api/external/his/sync-patient患者预约/建档推送
POST/api/external/his/sync-catalog基础字典同步

3. Scope 隔离

接口所需 Scope
ping（无）
patient_get / visit_list / visit_statuspatient:read
order_list / evidence_verifyreport:query
sync-patientpatient:sync
sync-catalogcatalog:sync

Scope 在「授权 Scope」中以空格分隔填写；留空默认 *（全部）。缺少 Scope 返回 403。

4. 测试方法

# 自检
curl "http://127.0.0.1:8000/api/external/his/read?action=ping" -H "X-HIS-Token: <Token>"

# 患者查询
curl "http://127.0.0.1:8000/api/external/his/read?action=patient_get&patient_no=FHD0001" \
  -H "X-HIS-Token: <Token>"

# 建档推送
curl -X POST http://127.0.0.1:8000/api/external/his/sync-patient \
  -H "X-HIS-Token: <Token>" -H "Content-Type: application/json" \
  -d '{"id_card":"320102198001150011","name":"张三","gender":"男"}'

Token 无效返回 401；Scope 不足返回 403（均可在「同步监控 → 入向调用审计」中溯源）。
