LIS 实验室检验双向闭环 接口帮助

出向下发检验申请；入向接收检验中心异步 Webhook 报告回调，验签后按申请单号幂等回填明细与报告。
1. 出向申请下发2. 入向报告回调3. 测试

1. 出向申请下发

  • 启用申请下发：开启后检验开单自动推送。
  • LIS 接收申请 API：目标地址；调用凭证 Token：请求携带 X-LIS-Token。

2. 入向报告回调

  • Webhook 验签密钥：回调方须携带 X-LIS-Token: <密钥>（或 ?token=）。点「生成密钥」自动生成。留空 = 拒绝全部回调。
  • 验签密钥过期时间 / 状态 / Scope：生命周期与权限控制（Scope 需包含 report:write）。
  • IP 白名单：建议限定检验中心出口 IP。

回调 JSON：

{
  "order_no": "JY2026100114224692",
  "report_doctor": "李检验",
  "pdf_url": "http://lis/reports/1.pdf",
  "items": [
    { "name": "白细胞计数(WBC)", "value": "12.3", "unit": "10^9/L", "ref_range": "3.5-9.5", "flag": "H" }
  ]
}

3. 测试方法

curl -X POST http://127.0.0.1:8000/api/external/lis/callback \
  -H "X-LIS-Token: <验签密钥>" -H "Content-Type: application/json" \
  -d '{"order_no":"JY2026100114224692","items":[{"name":"白细胞计数(WBC)","value":"12.3","unit":"10^9/L","ref_range":"3.5-9.5","flag":"H"}]}'

成功返回 {"ok":true,...}；Token 无效返回 401；缺少 Scope 返回 403。

同一报告重复推送执行覆盖性更新（幂等），不会重复插入。
