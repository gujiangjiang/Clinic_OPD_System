DICOM / PACS 影像互联 接口帮助

支持两种通道：DICOMweb（HTTP RESTful，推荐）与传统 DIMSE（TCP）。本系统可出向调阅 PACS，也可入向作为轻量 DICOMweb 服务供 PACS 浏览器联调。
1. 介绍 2. 出向配置 3. 鉴权怎么填 4. 入向 DICOMweb 5. 测试方法 6. 常见问题

1. 介绍

协议特点
DICOMweb基于 HTTP 的 DICOM：QIDO-RS 检索、WADO-RS 调阅、STOW-RS 上传，便于与 Web 阅片器/云 PACS 集成。
DIMSE传统 TCP DICOM（C-STORE / C-MOVE），通常由 PACS 前置网关承载监听端口。
本系统只存储影像「引用与元数据」（Study/Series UID、modality、张数、存储区 region），不存影像二进制。

2. 出向配置（本系统调阅外部 PACS）

  • 协议通道：选择 DICOMweb 或 DIMSE。
  • QIDO-RS 检索端点：如 http://pacs.hospital.local/dicomweb/studies
  • WADO-RS 调阅端点：如 .../dicomweb/studies/{study_uid}/series
  • STOW-RS 上传端点：如 .../dicomweb/studies
  • Web 阅片器 URL 模板：支持 {study_uid} 变量，如 https://viewer/viewer?study={study_uid}

3. 鉴权怎么填（重点）

出向 DICOMweb 的鉴权拆成两部分，避免手写请求头出错：

  • 鉴权方式（下拉）：无鉴权 / Bearer Token / API Key / Basic Auth / 自定义头。
  • 鉴权值（输入框）：只填「值」，系统自动拼装为正确请求头。
鉴权方式鉴权值填什么实际发出的请求头
Bearer TokenToken 原文，如 304f90c69fae2b47Authorization: Bearer 304f90c69fae2b47
API KeyKey 原文，如 304f90c69fae2b47X-API-Key: 304f90c69fae2b47
Basic Auth用户名:密码Authorization: Basic <base64(用户名:密码)>
自定义头头名: 头值原样发送该头
不要再填 Bearer: xxx、X-API-Key: xxx（带冒号）或带前缀的整段字符串——这些都是错误的；只在下拉里选择方式、在输入框里填纯值即可。

4. 入向 DICOMweb（供 PACS 浏览器调阅本系统）

开启「启用入向 DICOMweb」并配置 Token 后，本系统对外提供：

方法路径说明
GET/api/dicomweb/studiesQIDO-RS 检查检索，参数 PatientID / StudyInstanceUID / Modality / StudyDate
GET/api/dicomweb/studies/{studyUID}/series序列检索
GET/api/dicomweb/studies/{studyUID}/metadataWADO-RS 实例元数据（DICOM JSON，不含像素）

入向 Token 与 FHIR 一致：请求头 X-API-Key: <Token> 或 Authorization: Bearer <Token>，只填纯 Token。

标签约定：PatientID(0010,0020)=患者号；OtherPatientIDs(0010,1000)=门诊号（就诊流水号，本服务约定）；AccessionNumber(0008,0050)=检查号（申请单号 JC…，非报告号）；PatientAge(0010,1010)=年龄、PatientBirthDate(0010,0030)/PatientSex(0010,0040)。仅影像检查（orders.order_type=imaging）出现在 DICOMweb/ImagingStudy 中。

5. 测试方法

# 出向：在「状态总览 → 连通性测试」按当前配置探测 QIDO/WADO/STOW 可达性

# 入向 QIDO-RS 检索
curl -H "X-API-Key: <你的入向Token>" \
  "http://127.0.0.1:8000/api/dicomweb/studies?PatientID=FHD0001"

# 入向 序列检索（先从上一步取 StudyInstanceUID）
curl -H "X-API-Key: <你的入向Token>" \
  "http://127.0.0.1:8000/api/dicomweb/studies/<StudyUID>/series"

# 入向 元数据
curl -H "Authorization: Bearer <你的入向Token>" \
  "http://127.0.0.1:8000/api/dicomweb/studies/<StudyUID>/metadata"
若使用本项目的「模拟 Web PACS 影像浏览器」，可在其数据源配置里填写本系统的 QIDO/WADO 地址与入向 Token 完成联调。

6. 常见问题

  • 一直提示 token 错误：确认是「值」而不是整段头；确认 Token 与系统配置一致；确认来源 IP 在白名单内。
  • QIDO 无结果：确认该患者已登记影像引用（检查报告出具后自动登记）；
  • DIMSE 端口连不上：本系统不直接起 TCP 监听，需由 Orthanc/dcm4chee 等前置网关承载。
