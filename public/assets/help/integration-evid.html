存证 / 电子签名 接口帮助

为电子病历、诊断证明提供内容完整性与签名存证能力，可选本地哈希或对接外部 CA / 时间戳服务。

1. 存证模式

模式说明
关闭不进行存证。
本地哈希指纹保存/开具时计算 SHA-256 摘要入库，自证内容未被篡改，无需外部服务。
外部存证服务调用自定义 HTTP 接口对接 CA / 时间戳服务，保存返回的存证凭据（token/signer/time）。

2. 参数

  • 外部存证/签名服务接口地址：HTTP 端点。
  • 存证服务认证令牌：调用外部服务时携带。
  • 电子签名人（印章信息）：写入病历/证明的签名人展示。

3. 验真

外部机构可通过 HIS 入向只读接口 action=evidence_verify 按 record_id 或 cert_no 核验存证指纹与凭据。

curl "http://127.0.0.1:8000/api/external/his/read?action=evidence_verify&cert_no=ZM..." \
  -H "X-HIS-Token: <Token>"

哈希模式无需连通性测试；外部服务模式可在「状态总览 → 连通性测试」探测。
